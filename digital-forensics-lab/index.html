          Investigator's Field Guide
        

        
      

      

        

          

            1. The Golden Rule: Facts Over Guilt
            Digital evidence records only what machines did—never human intent. If employee Elena's account is used to log in at midnight, that proves Elena's password was entered, NOT that Elena was sitting at the computer. Always look for stolen credentials or session hijacking.
          

          

            2. Temporal Correlation (Timelines)
            Attackers rarely act without patterns. Look for threshold triggers: failed logins right before a success, automated script blocks executed right after privilege elevation, or file deletions right before logs are wiped.
          

          

            3. Detecting Anti-Forensics (Timestomping & Purges)
            Attackers often try to hide their tracks. In Windows NTFS file systems, comparing the $STANDARD_INFORMATION timestamp with the Master File Table ($MFT) reveals if a file was deliberately backdated.
          

          

            4. Remediation First
            Containment always comes first: terminate active sessions, isolate rogue IP addresses or MACs, and capture volatile RAM before rebooting victim machines.
